# AudioGuide: админ-панель

Веб-приложение для редакторов и администраторов. Редакторы управляют точками, маршрутами, медиа и публикацией. Администраторы дополнительно управляют пользователями и удалением.

## Роли

- **editor**: создание/редактирование точек и маршрутов, загрузка медиа, публикация контента
- **admin**: + управление пользователями, удаление маршрутов, удаление (cascade) точек, входящих в маршруты

## Структура

- **app.js** — инициализация, переключение экранов (map, points, routes, users)
- **auth.js** — проверка сессии, форма входа, управление текущим пользователем
- **api.js** — нормализованные HTTP запросы с обработкой ошибок из `{"detail": "..."}`
- **points.js** — редактор точек (создание, редактирование, загрузка изображения/аудио)
- **routes.js** — редактор маршрутов (CRUD, привязка точек, загрузка обложки)
- **users.js** — список пользователей, смена роли, деактивация (для админов)
- **map.js** — Яндекс.Карты для админа, плейсмарки точек, просмотр маршрутов
- **media.js** — валидация файлов, upload на собственный `/manage/media`
- **dom.js** — безопасное построение DOM, модальные окна, диалоги
- **config.js** — статические параметры (API base, координаты карты)

## Развёртывание

**Локально**: `python3 dev/mock_server.py 8766`

Mock учетные данные (см. `dev/mock_server.py`, функция `seed()`):
- admin@example.com / admin-password-1 (админ)
- ed@example.com / editor-password-1 (редактор)

**На сервер**: static файлы → `/var/www/admin` via `audioguide-backend/deploy/scripts/deploy.sh admin`

## Технические детали

- **API**: same-origin (куки сессии + заголовок `X-Requested-With: fetch`)
- **Медиа**: файлы хранятся на своём сервере (`/media/...`, отдаётся nginx'ом), загрузка — `POST /api/v1/manage/media` (multipart)
- **Нет шага сборки**: нативные ES modules
- **Модули**: importable в Node для тестирования (ничего не касается `window`/`document` на уровне импорта)
